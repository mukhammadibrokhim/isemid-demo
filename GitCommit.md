# Git Commit Prefixes (Conventional Commits)

| Prefix   | Meaning                   | Example                                    | Notes                                              |
|----------|---------------------------|--------------------------------------------|----------------------------------------------------|
| feat     | New feature               | feat: add user login API                    | Use when adding new functionality                  |
| fix      | Bug fix                  | fix: resolve null pointer exception         | Use when fixing bugs                                |
| docs     | Documentation update     | docs: update README with setup instructions | Changes only to documentation                      |
| style    | Code style / formatting  | style: reformat code with prettier           | Changes that do not affect code functionality      |
| refactor | Code refactoring         | refactor: simplify user service logic        | Code improvements without changing behavior        |
| test     | Adding or updating tests | test: add unit tests for payment service     | Adding or modifying tests                           |
| chore    | Maintenance tasks        | chore: update dependencies                    | Other changes like build scripts, configs, etc.   |
